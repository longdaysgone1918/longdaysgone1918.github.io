Gallery photos. Each folder here is one album, for example:
  src/assets/gallery/1/IMG_2.jpg
Drop jpg, jpeg, png or webp files into an album folder and they appear automatically.
Photos placed directly in this folder (not in an album folder) are shown as "Unsorted".
Use English letters, numbers and hyphens for folder names: they appear in the web address.
Before committing, run:  node scripts/clean-photos.mjs
It removes location and other hidden information (these files are published in the public GitHub repository).
iPhone HEIC photos are not supported: convert them to JPG first, or set the iPhone camera to "Most Compatible".
